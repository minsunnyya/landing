용어 사전

어려운 말, 한 줄로 풀었습니다

가이드 글에 나오는 홈페이지·검색 용어를 쉬운 말로 정리했습니다. 글 속 밑줄 친 단어를 누르면 이 페이지로 옵니다.

AI 검색 대응
ChatGPT·네이버 AI 브리핑·구글 AI 요약 같은 AI 검색이 내 글을 찾아 인용하기 쉽게 만드는 일. GEO(생성형 검색 최적화)라고도 합니다.
AI 브리핑
네이버 검색 결과 맨 위에 AI가 여러 글을 요약해 보여 주는 답변. 출처로 쓴 글의 링크가 함께 나옵니다.
AI 요약
구글 검색 결과 맨 위에 AI가 요약해 보여 주는 답변(AI Overviews). 출처 링크가 함께 나옵니다.
IndexNow
새 글이나 바뀐 글을 검색엔진에 바로 알리는 방법. 빙(Bing)·네이버 등이 지원합니다.
RSS
새 글 목록을 자동으로 알려 주는 파일. 네이버 서치어드바이저에 제출하면 새 글을 빨리 가져갑니다.
llms.txt
AI에게 사이트 요약을 알려 주려고 두는 텍스트 파일. 아직 공식 표준은 아니지만 두어서 손해 볼 일은 없습니다.
개인정보처리방침
어떤 개인정보를 왜 받고, 얼마나 보관하고, 어떻게 지우는지 적어 공개하는 문서. 개인정보를 받는다면 필요합니다.
고유식별정보
주민등록번호·여권번호·외국인등록번호·운전면허번호처럼 한 사람을 특정하는 번호. 법으로 특히 엄격하게 다룹니다.
구글 비즈니스 프로필
구글 지도·검색에 사무소 정보를 올리고 관리하는 무료 서비스. 외국인 고객이 많이 봅니다.
구조화 데이터
사무소 이름·주소·전화·자주 묻는 질문 같은 정보를 검색엔진과 AI가 정확히 알아보도록 페이지 안에 따로 적어 두는 표시. 방문자 눈에는 보이지 않습니다.
도메인
홈페이지 주소. 예: worksframe.com. 사무소 명의로 등록하고 매년 갱신합니다.
리디렉션
옛 주소로 들어온 사람을 새 주소로 자동으로 보내 주는 설정. 홈페이지 주소를 바꿀 때 필요합니다.
보안 인증서
주소 앞에 https와 자물쇠 표시가 뜨게 하는 인증서(SSL). 없으면 브라우저가 ‘안전하지 않음’이라고 경고합니다.
사이트맵
홈페이지에 있는 페이지 목록을 검색엔진이 읽기 좋게 정리한 파일. 보통 /sitemap.xml 주소에 있습니다.
색인
검색엔진이 페이지를 읽어 검색 결과에 올릴 수 있게 저장해 두는 것. ‘수집’이라고도 합니다. 색인이 안 되면 검색에 나오지 않습니다.
서치 콘솔
구글이 무료로 주는 사이트 관리 도구. 내 홈페이지를 구글에 알리고, 어떤 검색어로 들어오는지 봅니다.
서치어드바이저
네이버가 무료로 주는 사이트 관리 도구. 내 홈페이지를 네이버에 알리고, 수집 상태와 검색 현황을 봅니다.
스마트플레이스
네이버 지도·플레이스에 업체를 등록하고 정보를 관리하는 네이버 서비스. 등록은 무료입니다.
추천·보증
돈이나 혜택을 받고 쓴 후기·추천. 그 사실을 밝혀야 한다는 것이 공정거래위원회 심사지침의 취지입니다.
카카오톡 채널
사업자용 카카오톡 계정. 개인 카톡과 분리해 고객 상담을 받을 수 있습니다.
클릭 단가
광고를 한 번 클릭할 때 나가는 돈(CPC). 경쟁이 센 키워드일수록 비쌉니다.
키워드
고객이 검색창에 입력하는 말. 예: ‘수원 공장등록 대행’.
파워링크
네이버 검색 결과 위쪽에 나오는 광고. 클릭할 때마다 돈이 나갑니다.
호스팅
홈페이지 파일을 올려 두는 인터넷 서버 공간. ‘홈페이지 집세’라고 생각하면 쉽습니다.
